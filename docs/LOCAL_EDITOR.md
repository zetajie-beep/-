# 线上管理员后台与本机预览

## 线上使用方式

完成云后台配置后，站主打开 `https://portfolio-website-jsbq.vercel.app/?studio=1`，使用管理员邮箱和密码登录。

1. 登录后修改各模块文案、项目封面和项目缩略图。
2. 草稿自动保存，点击“预览网站”检查效果。
3. 点击“发布”后，内容写入云数据库；访客下次打开或刷新页面即可读取新内容，无需重新部署网站。
4. 使用完毕点击“保存并退出”。

首次接入云后台仍需部署一次代码和 Vercel 环境变量。之后只有修改网站代码、布局或功能才需要重新部署；普通文案、项目与图片更新在后台发布即可。

## 权限与入口

- 公开网站默认不显示后台图标；站主可收藏上述后台地址。进入后台并完成管理员验证后显示线性用户图标。
- 本机开发预览保留导航栏用户图标，方便调试。
- 知道后台地址不等于拥有编辑权限：生产环境必须通过 Supabase Auth 登录，并由数据库与存储的 RLS 校验管理员权限。
- 不开放前端注册表单；云服务也必须关闭公开注册，仅由受信任的后台工具创建站主账号。
- 密码、私密 API 密钥和管理员权限不能写入前端代码或提交到 GitHub。
- 云配置缺失时显示配置提示，不会自动放开编辑权限。账号需要实际创建后才能登录。

## 未配置云后台时的本机预览

运行 `npm run dev` 后，从 `http://127.0.0.1:5173/?studio=1` 可进入本机编辑。
仅开发环境且主机为 loopback，并且未配置 Supabase 时允许免登录。
不要把开发服务器通过局域网或隧道开放给其他人。

本机草稿与发布内容保存在当前浏览器 localStorage；上传图片保存在 `public/assets/local-uploads/`。
此时后台标注“仅本机”，“发布”只更新本机预览，不会更新公网、GitHub 或 Vercel。
已有本机草稿不会被自动删除，也不会被自动上传到云端；首次迁移前需要确认希望发布的内容与图片。

数据库、存储、管理员权限及环境变量配置见 [CMS_SETUP.md](./CMS_SETUP.md)。
