# ZET 在线内容后台使用说明

## 进入后台

打开 [管理员登录入口](https://portfolio-website-jsbq.vercel.app/?studio=1)，输入单独交付的管理员账号与密码。

- 普通访客的导航栏不显示后台入口。
- 知道入口网址也不代表可以编辑：必须登录管理员账号，数据库和图片存储还会独立检查权限。
- 不开放公开注册和匿名登录。目前只创建了你的管理员账号。
- 密码不在项目源码里。请把单独交付的登录信息存入密码管理器，不要上传到 GitHub、网站或分享给他人。

## 编辑与发布

1. 登录后打开「内容面板」，选择首屏、项目、个人经历、个人优势或联系方式。
2. 修改文案、标题、封面和图片；等待「草稿已保存」。草稿保存不等于公开发布。
3. 用「预览网站」检查效果。
4. 点击「发布」，确认后将草稿更新为公开版本。
5. 访客重新打开或刷新网站，即可读取新内容。结束后点「保存并退出」。

项目封面是单独一张，项目缩略图最多 20 张，不含封面。支持 JPG、PNG、WebP 和 AVIF；每张图片最大 6 MB。

图片上传到用于网站展示的公开存储空间，知道图片完整链接的人可以访问，即使对应草稿还未发布。不要上传机密或不准备公开的文件；草稿文案和历史版本则只有管理员能读取。

## 哪些更新不用重新部署

后台已有字段中的文字、项目封面、图库、联系方式等内容，点击发布即可更新，无需上传 GitHub 或重新部署 Vercel。

新增页面结构、修改布局、动效或功能，仍属于代码更新，需要部署。此次已直接更新现有 Vercel 项目，但没有替你提交或推送 GitHub；以后通过 GitHub 更新代码前，请先同步这份本机源码，避免用旧版本覆盖后台功能。

## 原来的本机草稿

首次云端发布以本次项目源码中的默认内容为基础。原来仅保存在浏览器中的本机草稿没有被删除，也没有自动复制到云端；如果发现有此前本机编辑的内容未出现，可以再单独迁移，不要先清空浏览器数据。

## 服务与维护

- 网站：Vercel 的 `portfolio-website-jsbq` 项目。
- 内容与图片：[Supabase 项目控制台](https://supabase.com/dashboard/project/txlfafqgtewziwxuzbgr)，项目名 `zet-portfolio-cms`，新加坡区域。
- 本次使用免费组织，没有购买付费套餐或增值服务。免费套餐存在空间、流量限制，长时间不活跃的项目可能暂停；详见 [Supabase 套餐说明](https://supabase.com/pricing)。
- 本机 `.env.local` 及 Vercel 环境变量只配置浏览器可用的 Supabase 地址与 Publishable Key；管理员密码及服务端密钥不能放入 `VITE_*` 环境变量。

如果页面暂时显示旧内容，先刷新并检查网络。云端读取较慢时页面会先显示随代码附带的内容，再在读取成功后更新；网络持续失败或项目暂停时则保留兜底页面。
